# CLAUDE.md

Operating rules for coding agents working in this repository. Read this file, then `DOCS.md`, before writing code. `PRD.md` defines what to build, `PLAN.md` defines the order.

## What this is

**Strata** — an archaeology tool for BasePaint canvases. Every daily canvas is painted by hundreds of people over 24 hours, and pixels get painted over. The final PNG is only the top layer. Strata replays the on-chain stroke history and shows what is buried underneath: who painted each pixel, how many times it was overpainted, what the canvas looked like at any moment, and how much of each artist's work survived to the final image.

Live data only. Every number on screen is derived from the BasePaint indexer or the BasePaint theme API at runtime.

## Stack

- Vite 8 + React 19 + TypeScript 6 (strict) — whatever `npm create vite@latest` scaffolds
- React Router (browser router, no hash routing)
- Canvas 2D + `ImageData`, replay work in a Web Worker
- `viem` for ENS lookups and for the mint transaction
- `idb-keyval` for the decoded-day cache
- Vercel for hosting; one Edge Function for share images
- No component library, no CSS framework, no state manager. Plain CSS with custom properties in `src/styles/tokens.css`.

## Commands

```bash
npm install
npm run introspect     # writes src/data/schema.json from the live GraphQL endpoint
npm run dev            # vite dev server on :5173
npm run typecheck      # tsc --noEmit
npm run lint           # oxlint, what the Vite template now ships
npm run verify -- 500  # replays day 500 in node and diffs against the official PNG
npm run test           # vitest, runs the decoder + replay tests
npm run build          # tsc --noEmit && vite build
```

`npm run introspect` must be run once before the first build on a clean checkout. It is a real network call; do not commit a hand-written `schema.json`.

## Hard rules

**No mock data.** No fake artists, no invented pixel counts, no lorem, no `TODO`, no commented-out "real implementation goes here". If a value cannot be fetched, the UI says so in plain words and offers a retry — it does not display a fabricated number. Test fixtures are allowed only when they are real captured API responses, produced by `scripts/capture-fixture.mjs` and committed with the day number in the filename.

**No placeholder UI.** Every screen ships with real loading, empty, and error states. "Loading" means a progress count of strokes decoded, not a spinner with no information. An error state names what failed and what the person can do.

**Never guess the schema.** Root GraphQL field names come from `src/data/schema.json`. If a query fails, re-run `npm run introspect` and fix the document — do not add a fallback that silently returns nothing.

**Never hardcode canvas size.** It is 144 for days 1–365 and 256 from day 366, but read `size` from the theme API response for every day. The same applies to the palette.

**URL is state.** Day, playback position, view mode, and selected pixel all live in the URL: `/day/742?t=18400&mode=depth&px=91,204`. Every interesting view must be linkable. This is what makes the tool shareable, and sharing is how it gets used.

**Typed arrays for pixel data.** Never build an array of per-pixel objects for a 256×256 canvas. Layer buffers are `Uint8Array`/`Uint16Array`, indexed `y * size + x`. Per-pixel history is computed on demand by rescanning the stroke list, not stored.

**Replay off the main thread.** All decoding and replay happens in `src/workers/replay.worker.ts`. The main thread only receives transferable buffers.

**`image-rendering: pixelated` everywhere.** Canvas artwork must stay crisp at every zoom level. This is non-negotiable; it is the single most obvious sign of a careless BasePaint client.

**Accessibility floor.** Keyboard focus is visible. The pixel inspector is reachable with arrow keys, not only with a mouse. `prefers-reduced-motion` disables autoplay of the scrubber. Colour is never the only carrier of meaning.

## Data facts the code depends on

- Day 1 started at Unix `1691599315`. Each day is exactly `86400` seconds. `currentDay = Math.floor((now - 1691599315) / 86400) + 1`.
- A `Stroke.data` hex string decodes in 3-byte chunks after `0x`: byte 0 = x, byte 1 = y, byte 2 = palette index.
- Replaying every stroke for a day in `id` order reconstructs the official final image. This is verifiable and must stay verified — see `npm run verify`.
- All BasePaint artwork is CC0. Rendering, remixing, and redistributing it is allowed without attribution, but the app credits artists by address everywhere anyway, because crediting is the point of the product.

## Style

- TypeScript strict. No `any`. No non-null assertions on data from the network.
- Functions in `src/core/` are pure and synchronous, take plain data, and are unit tested. All the interesting logic lives there.
- No default exports except React route components.
- Comments explain why, not what. The decoder and the survival definition get a comment; a `useState` does not.
- Keep dependencies at the list above. Adding one requires deleting one.

## Definition of done for any task

1. `npm run typecheck`, `npm run lint`, and `npm run test` pass.
2. The feature works against the live indexer for a heavy day (try day 500 and day 1000) and for today's in-progress canvas.
3. Loading, empty, and error states exist and were looked at.
4. The view is linkable — reload the URL and land in the same state.
5. Mobile at 390px wide is usable, not just non-broken.
